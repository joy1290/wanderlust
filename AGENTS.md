## Stack

- Next.js 16.4.3 App Router + React 19.3.0, single route: `src/app/page.tsx` (currently near-empty; root layout in `src/app/layout.tsx`)
- Tailwind CSS v4 (CSS-first: `@import "tailwindcss"` in `globals.css`, no tailwind config file) via `@tailwindcss/turbopack`
- shadcn/ui, style `base-nova` (`components.json`); 63 components pre-installed in `src/components/ui/` — check there before writing new primitives
- React Compiler enabled (`next.config.ts` → `reactCompiler: true`); also `cacheComponents` + `partialPrefetching` on
- Strict TypeScript, path alias `@/*` → `./src/*`

## Conventions

- Class merging: `import { cn } from "cn"` (the `cn` package, used directly by all shadcn components). `src/lib/utils.ts` re-exports it as `@/lib/utils`, but no file imports that path yet — match whichever you're editing.
- New shadcn components: `npx shadcn add <component>` (config in `components.json`, aliases `@/components`, `@/lib`, `@/hooks`)
- Custom hooks live in `src/hooks/`; global CSS + design tokens (CSS variables, `.dark` class theming) in `src/app/globals.css`
